# Stack پیشنهادی (نسخه‌ی ۱)

روی یک سرور Ubuntu با Docker Compose اجرا می‌شود.

| بخش | انتخاب | توضیح برای آدم غیربرنامه‌نویس |
|---|---|---|
| سرور | **Ubuntu** | سیستم‌عامل رایگان و پایداری که بیشتر سرورهای اینترنتی با آن کار می‌کنند. |
| اجرا | **Docker Compose** | همه‌ی بخش‌های سایت را در جعبه‌های جدا بسته‌بندی می‌کند تا با یک دستور روشن شوند و روی هر سروری یک‌جور کار کنند. |
| صفحه‌ها | **Next.js** | صفحه‌هایی را می‌سازد که مشتری روی گوشی می‌بیند و آن‌ها را سریع نشان می‌دهد. |
| سرویس داده | **Express** | واسطه‌ای که منو را از دیتابیس برای صفحه‌ها می‌آورد و نظر مشتری را در دیتابیس ذخیره می‌کند. |
| دیتابیس | **PostgreSQL** | دفتر مطمئنی که منو و نظرها در آن نگه داشته می‌شوند و با خاموش شدن سرور پاک نمی‌شوند. |
| دروازه | **Caddy** | دربانی که درخواست‌ها را به بخش درست می‌فرستد و قفل امنیتی HTTPS سایت را خودکار می‌گیرد و تمدید می‌کند. |
| ابزار کمکی | کتابخانه‌ی **qrcode** | تصویر QR هر میز را خودکار می‌سازد تا لازم نباشد دستی درستشان کنیم. |
| ابزار کمکی | فونت **Vazirmatn** روی همین سرور | فونت فارسی رایگان و خوانا که از سرور خودمان بارگذاری می‌شود و به سرویس‌های خارجی وابسته نیست. |

یک نکته: Next.js به‌تنهایی هم می‌تواند کار Express را انجام دهد. چون Express خواسته شده، نگه داشته شده است. هزینه‌اش این است که یک جعبه‌ی بیشتر باید نگهداری شود.
